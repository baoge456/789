1 📁 创建项目目录 & 缓存文件夹
bash · 在 VPS 中执行

mkdir -p cache
2 ✍️ 创建 docker-compose.yml（1Panel Redis 配置）
YAML · 使用 1Panel 本地 Redis 存储 
version: '3.8'

services:
  moontvplus:
    image: ghcr.io/mtvpls/moontvplus:latest
    container_name: moontvplus
    restart: unless-stopped
    ports:
      - '3000:3000'
    environment:
      - NODE_ENV=production
      - USERNAME=baoge
      - PASSWORD=wsb123456
      - ENABLE_TVBOX_SUBSCRIBE=true
      - TVBOX_SUBSCRIBE_TOKEN=baoge888
      - NEXT_PUBLIC_STORAGE_TYPE=redis
      - REDIS_URL=redis://:redis_zppwFr@172.245.88.184:6379
    volumes:
      - ./cache:/app/.cache

💡 REDIS_URL 中的密码请替换为 1Panel Redis 实际密码，可通过 docker exec 1Panel-redis-yiBC env | grep REDIS_PASSWORD 查看。

⚙️ 常用运维命令

# 停止并移除容器

# 更新镜像

# 进入容器内部

🐞 故障排查指南

❌ 容器无法启动 → docker logs moontvplus

🔌 端口冲突 → 修改左侧端口如 8080:3000

🗄️ Redis 连接失败（方案一） → 确认 1Panel Redis 运行状态及密码

☁️ Upstash 连接失败（方案二） → 检查网络能否访问 upstash.io
