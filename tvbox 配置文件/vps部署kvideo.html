2 ✍️ 创建 docker-compose.yml（Upstash Redis 持久化）
YAML · 包含 Upstash 云端存储 
version: '3.8'

services:
  kvideo:
    image: kuekhaoyang/kvideo:latest
    container_name: kvideo
    restart: unless-stopped
    ports:
      - '3100:3000'               # 宿主机端口:容器端口
    environment:
      - NODE_ENV=production
      - PORT=3000
      - NEXT_PUBLIC_SITE_NAME=宝哥影院
      - NEXT_PUBLIC_SITE_TITLE=宝哥影院 - 全网影视聚合
      - NEXT_PUBLIC_SITE_DESCRIPTION=高清影视聚合搜索平台
      - ADMIN_PASSWORD=baoge666   # 管理员密码（仅密码登录）
      - PERSIST_SESSION=true
      - MERGE_SOURCES=true
      # Upstash Redis 配置（与moontvplus.653827.xyz(baoge6789)共用，数据隔离）
      - UPSTASH_REDIS_REST_URL=https://worthy-donkey-58808.upstash.io
      - UPSTASH_REDIS_REST_TOKEN=AeW4AAIncDE1MjY3ZTZmMWQyYTY0NTc0OTQzMGJmZWJkMzVmYzE0OHAxNTg4MDg

🐞 故障排查指南

❌ 容器无法启动 → docker logs kvideo 查看错误，检查端口 3100 是否被占用。

🔄 添加订阅源后刷新丢失 → 确认 Upstash Redis 环境变量正确，查看日志是否有 Upstash Redis connected。

🌐 域名无法访问 → 检查 Nginx 反代配置是否正确，执行 nginx -t && systemctl reload nginx。

🔑 登录密码错误 → 确认环境变量 ADMIN_PASSWORD=baoge666，清除浏览器缓存后重试。

📦 Upstash 连接失败 → 检查网络是否能访问 worthy-donkey-58808.upstash.io，必要时更换区域。
