📊 基础查询
1 查看 Redis 进程
ps aux | grep redis-server | grep -v grep
2 查看 Redis 容器状态
docker ps | grep redis
3 查看数据库总数
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr CONFIG GET databases
4 查看所有数据库键数量
for db in {0..15}; do echo -n "db$db: "; docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n $db DBSIZE 2>/dev/null; done
✅ 这是一行完整命令，点击复制后直接粘贴回车即可
5 查看 db0 所有键
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n 0 KEYS "*"
6 查看 db0 键数量
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n 0 DBSIZE
7 查看所有数据库分布
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr INFO keyspace
🔎 数据查询
1 查看字符串类型键的值
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n 0 GET "admin:config"
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n 0 GET "user:list"
2 查看哈希类型键的值
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n 0 HGETALL "user:baoge:info"
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n 0 HGETALL "user:123:info"
3 查看键的类型
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n 0 TYPE "user:baoge:info"
4 查看键的剩余存活时间
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n 0 TTL "user:baoge:info"
5 查看 db1 数据
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n 1 KEYS "*"
docker exec 1Panel-redis-yiBC redis-cli -a redis_zppwFr -n 1 DBSIZE
