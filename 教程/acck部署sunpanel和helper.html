🎨 第五步：在 Helper 中部署美化组件

5 让组件出现在 Sun-Panel 页面
  • ✅ 登录 Helper：https://helper.你的域名（账号 helper / 密码 helper123）
  • ✅ 进入「组件市场」，选择一个组件（如“时钟”）
  • ✅ 编辑组件，“Helper域名前缀” 填写：https://helper.你的域名
  • ✅ 点击「应用到固定组件池」
  • ✅ 进入「固定组件」页面，将组件拖拽到右侧布局区域
  • ✅ 点击右上角「部署配置」
  • ✅ 刷新 Sun-Panel 页面（https://sunpanel.你的域名），美化效果出现！
💡 为什么必须用域名？
如果 Helper 用 IP+端口访问，生成的资源链接是 HTTP 的，而 Sun-Panel 是 HTTPS 的，浏览器会阻止混合内容，导致组件不显示。

📋 完整命令速查表

🚀 一键复制所有关键命令 
# 1. 安装科技lion脚本
bash <(curl -sL kejilion.sh)

# 2. 查看 Sun-Panel 挂载路径
docker inspect sun-panel --format='{{range .Mounts}}{{printf "%s -> %s\n" .Source .Destination}}{{end}}'

# 3. 创建 custom 目录（关键！）
mkdir -p /home/docker/sun-panel/conf/custom

# 4. 创建 Helper 数据目录
mkdir -p /home/helper/{data,backups}

# 5. 部署 Helper 容器
docker run -d \
  --name sun-panel-helper \
  --restart unless-stopped \
  -p 33002:80 \
  -e BACKEND_PORT=3001 \
  -v /home/docker/sun-panel/conf/custom:/app/backend/custom \
  -v /home/helper/data:/app/backend/data \
  -v /home/helper/backups:/app/backend/backups \
  madrays/sun-panel-helper:latest

# 6. 验证 Helper 运行
docker ps | grep sun-panel-helper
curl http://127.0.0.1:33002

# 7. 运行科技lion 配置 Helper 域名
bash <(curl -sL kejilion.sh)
# 选择：10 LDNMP建站 -> 23 站点反向代理-IP+端口 -> 输入域名和端口33002
