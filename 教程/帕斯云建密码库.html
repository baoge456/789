📁 2. 创建 Vaultwarden 数据目录

mkdir -p /opt/vaultwarden/data
cd /opt/vaultwarden

⚙️ 3. 部署 Caddy + Vaultwarden (一键 HTTPS)

🧩 使用 Caddy 自动申请 Let's Encrypt 证书，配置极简，内存占用低，完美适配 256MB 机器。 
# 创建 Caddy 工作目录
mkdir -p /opt/caddy
cd /opt/caddy

# 创建 Caddyfile (域名已替换为真实地址)
cat > Caddyfile << 'EOF'
{
    email admin@baoge456.de5.net
}

mima.baoge456.de5.net {
    reverse_proxy vaultwarden:80
}
EOF

# 创建 docker-compose.yml (整合 vaultwarden 与 caddy)
cat > docker-compose.yml << 'EOF'
version: '3'

services:
  vaultwarden:
    image: vaultwarden/server:latest
    container_name: vaultwarden
    restart: always
    volumes:
      - /opt/vaultwarden/data:/data
    environment:
      - WEBSOCKET_ENABLED=true
      - SIGNUPS_ALLOWED=true
      - DOMAIN=https://mima.baoge456.de5.net
    expose:
      - 80

  caddy:
    image: caddy:latest
    container_name: caddy
    restart: always
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile
      - caddy_data:/data
      - caddy_config:/config

volumes:
  caddy_data:
  caddy_config:
EOF

# 启动服务 (拉取镜像并后台运行)
docker-compose up -d

🔍 4. 验证服务状态 & HTTPS 证书

# 查看容器运行状态
docker-compose ps

# 实时查看日志 (等待证书获取，看到 "serving https" 即成功)
docker-compose logs -f --tail 30

# 单独检查 caddy 日志是否成功获取 SSL
docker logs caddy | grep -i "certificate\|https"
✅ 当日志中出现 "certificate obtained successfully" 或 "serving https" 字样，说明 HTTPS 已生效！此时可以关闭日志（Ctrl+C）。

🚨 8. 排错指南 (纯IPv6重点)

问题现象解决方案
访问 https 显示 404 或无法连接1. 检查域名 AAAA 记录是否指向 2604:abc0:103:415:2::6c
2. 确保服务器 80/443 端口没有被防火墙拦截
3. 运行 docker-compose logs caddy 查看详细报错
证书申请失败 (acme error)需要确保 Let's Encrypt 能访问你的域名(IPv6)。先测试 curl -6 http://mima.baoge456.de5.net/.well-known/acme-challenge/test 应返回404(表示可访问)，且必须放开 80 端口。
docker 命令找不到执行 apk add docker docker-cli-compose && service docker start
IPv6 环境无法拉取镜像?Alpine 默认 IPv6 正常，若拉取缓慢可尝试 echo 'nameserver 2001:4860:4860::8888' > /etc/resolv.conf 临时使用 Google DNS。
内存不够导致容器被kill256MB 完全够用，若同时运行其他程序请释放。可限制 vaultwarden 内存：在 compose 中添加 mem_limit: 128m
