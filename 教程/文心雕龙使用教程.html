📝 文心雕龙

AI 驱动的中文文章创作助手 - 使用教程

🚀 快速开始

1 安装依赖
npm install
2 配置 API Key

在项目根目录创建 .env 文件，填入：

ZHIPU_API_KEY=你的智谱API密钥
💡 获取密钥：https://open.bigmodel.cn → 注册登录 → 创建 API Key
3 启动开发服务器
npm run dev
✅ 启动成功后访问：http://localhost:9002

📦 常用命令

启动开发服务器
npm run dev
生产构建
npm run build
启动生产服务器
npm start
类型检查
npm run typecheck

⚙️ 环境配置

.env 文件示例
ZHIPU_API_KEY=your_api_key_here
⚠️ 注意：.env 文件不会被提交到 Git，请妥善保管 API 密钥

🛠️ 故障排除

端口被占用
Get-Process -Name node | Stop-Process -Force

然后重新启动：npm run dev

重新安装依赖
rm -rf node_modules package-lock.json
npm install

📖 使用说明

  • 文章主题：输入文章的核心主题或关键词
  • 主题描述：可选，填写字数要求、情感基调、内容方向等
  • 文章风格：选择「杂文」或「散文」
  • 生成文章：点击按钮，AI 将自动生成 2000+ 字的文章
  • 预览编辑：支持 Markdown 实时预览和段首缩进
  • 复制下载：一键复制标准 Markdown 格式或下载 .md 文件
  • 历史记录：自动保存最近 50 篇文章
  • SEO 分析：查看字数、关键词密度等质量指标
  • Token 统计：显示配额使用情况和剩余量

💡 主题描述示例

请围绕城市生活与自然的对比展开，表达对慢生活的向往。字数要求：不低于2500字。希望文章带有淡淡的忧伤和温暖的情感。

你可以写：

  • ✍️ 情感基调（忧伤、温暖、激昂等）
  • 📏 字数要求（不低于2500字）
  • 🎯 内容方向（城市与自然对比、回忆童年等）
  • 🎨 文学手法（比喻、排比、对比等）
  • 📝 结构要求（总分总、倒叙等）

🎓 主题描述高级用法：指定文体

💡 重要提示：主题描述在所有风格下都有效！您可以在任何风格中要求使用特定文体（记叙文、议论文、说明文等），AI 会智能平衡风格要求和文体要求。

📖 记叙文模板（适合所有文学创作风格）

请用记叙文体裁。要求： - 以第一人称/第三人称视角 - 按时间顺序/倒叙展开 - 有具体人物描写（外貌、性格、动作） - 有场景描写（环境、氛围） - 有对话 - 情感真挚 字数：800-1200字
✅ 实际应用示例：
主题：故乡的老屋
类别：文学创作
风格：散文
主题描述：请用记叙文体裁，以第一人称视角，回忆童年在老屋的生活。要求有具体场景描写（夏日午后、奶奶的厨房、院子的枣树）。
✅ AI 会写散文，但采用记叙文手法，抒情与叙事结合

📝 议论文模板（适合杂文、报告）

请用议论文体裁。要求： - 开篇提出核心观点 - 从3个角度论证（并列/递进） - 每段有论据支撑（事例/数据/引用） - 有反驳对立观点 - 结尾总结升华 字数：1000-1500字
✅ 实际应用示例：
主题：人工智能对教育的影响
类别：文学创作
风格：报告
主题描述：请按议论文格式撰写。要求：摘要、引言、正文、结论；引用数据支撑观点；客观分析利弊；提出建议。字数：1500-2000字
✅ AI 会写报告，但融入学术论文结构

📋 说明文模板（适合报告、通知公告）

请用说明文体裁。要求： - 先定义/概述主题 - 分类别/分步骤说明 - 使用举例、比较、数据 - 语言客观准确 - 条理清晰（可用编号） 字数：800-1200字

🎯 更多创意组合

小说 + 议论文：
主题：AI时代的人际关系
风格：小说
主题描述：请在故事中融入学术论文的分析视角。要求：塑造一个研究AI的科学家角色；通过对话探讨技术伦理；结尾附上"参考文献"（虚构但格式规范）
诗歌 + 议论：
主题：时间的流逝
风格：诗歌
主题描述：请在诗中表达议论文式的思辨。要求：用意象对比过去与现在；每段结尾加入哲理性总结；语言要有论证的力度
杂文 + 记叙文：
主题：乡村振兴
风格：报告
主题描述：请用记叙文体裁，以第一人称视角，记录走访乡村的真实经历。要求有具体人物、场景描写、对话
⚠️ 注意事项：
• 如果主题描述与风格完全矛盾（如"诗歌 + 严格学术论文格式"），AI 可能会困惑
• 建议：主题描述应与风格有一定兼容性，AI 会智能平衡两者
• 最佳实践：风格定基调，主题描述补充具体手法和结构要求
