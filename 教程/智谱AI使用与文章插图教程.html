🤖 智谱 AI 平台使用教程

文心雕龙项目 AI 引擎操作指南

📋 你的当前配置

项目使用的模型：GLM-4-Flash
API 端点：https://open.bigmodel.cn/api/paas/v4/chat/completions
计费方式：按 Token 用量扣费（后付费）

📊 查看 Token 用量

1 访问智谱开放平台
https://open.bigmodel.cn/
2 登录账号

使用手机号或邮箱登录（注册时的账号）

3 进入控制台

点击右上角 "控制台" 按钮

4 查看用量统计

左侧导航栏 → "资源管理" → "Token 统计"

可以看到：

  • 📈 今日/本月 Token 消耗量
  • 💰 账户余额
  • 📉 每日用量趋势图
✅ 提示：GLM-4-Flash 模型非常便宜，100 万字约 1-2 元

💳 充值指南

1 进入充值页面

控制台左侧导航栏 → "资源管理" → "充值"

2 选择充值金额

系统提供多个档位（如 50 元、100 元、200 元等），也可自定义金额

3 选择支付方式

支持：支付宝 / 微信支付

4 完成支付

扫码或跳转支付，成功后余额即时到账

⚠️ 注意：账户余额不足时，API 调用会失败，项目会返回错误提示

💰 费用参考

模型 价格（每百万 Token） 适用场景
GLM-4-Flash（当前使用） 约 1-2 元 文章生成、日常创作
GLM-4 约 50 元 高质量长文
GLM-4V 约 60 元 图像理解
你的项目：每次生成 1000-2000 字文章，约消耗 2000-4000 Token
单次成本：约 0.002-0.004 元（几乎免费）
10 元可用：约 2500-5000 次

🔑 API 密钥管理

1 查看当前密钥

控制台左侧导航栏 → "API 密钥"

2 创建新密钥

点击 "创建密钥" → 设置名称 → 复制保存

3 配置到项目
# Vercel 环境变量
ZHIPU_API_KEY=你的密钥
⚠️ 重要：密钥只显示一次，创建后立即复制保存！

❓ 常见问题

Q1：如何知道余额是否充足？

控制台 → 资源管理 → Token 统计 → 查看"账户余额"
余额低于 10 元建议充值

Q2：Token 是怎么计算的？

中文字符 ≈ 1 个 Token
1000 字文章 ≈ 2000 Token（含 Prompt 和回复）

Q3：余额用完了会怎样？

API 调用失败，页面会提示错误。充值后立即恢复使用。

Q4：能设置每月消费上限吗？

智谱平台暂不支持设置上限，需自行关注余额。
建议：定期查看 Token 统计页面

🖼️ 文章插图使用指南

当前状态：文心雕龙生成的文章为纯文本格式，不包含图片。
如需插图，可手动在 Markdown 中添加图片链接。

方法一：使用网络图片

1 找到图片链接

从图片网站（如 Unsplash、Pexels）复制图片地址：
https://images.unsplash.com/photo-xxx.jpg

2 在 Markdown 中插入图片
![图片描述](图片链接)
3 示例
# 月光下的故乡
![月光洒在青石板上](https://images.unsplash.com/photo-1518837695005-2083093ee35b?w=800)
夜深了，月光如水...

方法二：使用本地图片

1 将图片保存到项目目录

例如：./images/moonlight.jpg

2 使用相对路径插入
![故乡的月亮](./images/moonlight.jpg)

方法三：导出 HTML 后嵌入图片

1 从文心雕龙导出 HTML 格式

点击"下载"按钮 → 选择"HTML"格式

2 用文本编辑器打开 HTML 文件

在适当位置添加图片标签：

<img src="https://images.unsplash.com/photo-xxx.jpg"
alt="月光下的故乡"
style="max-width: 100%;">
✅ 提示：推荐使用 Markdown 格式添加图片，后续可自由转换为其他格式

免费图片资源网站推荐

网站 特点 链接
