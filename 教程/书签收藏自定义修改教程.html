七、登录密码修改

⚠️ 重要： 密码不在前端代码中，需要在 Cloudflare Workers 环境变量中设置！

7.1 管理员密码

设置位置：Cloudflare Dashboard → Workers → 您的 Worker → 设置 → 变量

变量名说明示例值
ADMIN_PASSWORD管理员登录密码myAdmin123

7.2 公共访问密码

变量名说明示例值
PUBLIC_PASSWORD公共访问密码（留空则无需密码）public123

7.3 修改步骤

  1. 登录 Cloudflare Dashboard
  2. 进入 Workers & Pages → 选择您的 Worker
  3. 点击"设置" → "变量"
  4. 在"环境变量"部分，修改或添加上述变量
  5. 点击"保存并部署"
💡 提示： 如果 PUBLIC_PASSWORD 为空或未设置，则公共访问无需密码。
